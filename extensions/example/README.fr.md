# Example

🇬🇧 [English](README.md) · 🇪🇸 [Español](README.es.md)

Une note qui vous attend dans la barre d’outils : écrivez ce que vous voulez, elle sera encore là la prochaine fois.

## Installation

- **Firefox :** sur la page de l’extension du site catalogue, cliquez sur **Ajouter à Firefox**, puis confirmez.
- **Chrome :** téléchargez le fichier zip depuis la même page et décompressez-le. Ouvrez
  `chrome://extensions`, activez le **Mode développeur**, cliquez sur **Charger l’extension non
  empaquetée** et choisissez le dossier décompressé.

## Comment l’utiliser

Cliquez sur l’icône de l’extension dans la barre d’outils (dans Chrome, elle peut se trouver dans
le menu en forme de pièce de puzzle) et écrivez. La note est enregistrée au fil de la frappe,
uniquement dans votre navigateur.

Elle ne demande qu’une autorisation, le stockage, pour garder la note. Elle ne voit pas les pages
que vous visitez.
