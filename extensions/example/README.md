# Example

🇫🇷 [Français](README.fr.md) · 🇪🇸 [Español](README.es.md)

A note that waits in your toolbar: write anything, and it's still there next time you open it.

## Install

- **Firefox:** on the extension's page on the catalog site, click **Add to Firefox**, then confirm.
- **Chrome:** download the zip from the same page and unzip it. Open `chrome://extensions`, turn
  on **Developer mode**, click **Load unpacked** and choose the unzipped folder.

## How to use it

Click the extension's icon in the toolbar (in Chrome, it may be under the puzzle-piece menu) and
type. The note is saved as you type, in your browser only.

It asks for one permission, storage, to keep the note. It can't see the pages you visit.
