## Install

- **Firefox:** on the extension's page on the catalog site, click **Add to Firefox**, then confirm.
- **Chrome:** download the zip from the same page and unzip it. Open `chrome://extensions`, turn
  on **Developer mode**, click **Load unpacked** and choose the unzipped folder.
